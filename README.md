# ChatApp

A chat app, just for a hobby project.

Uses React for the frontend, Node.js/Express.js for the backend and socket.io for real-time updates.
Frontend and backend are separated.

*Check out the branch `better-UI` for a better UI designed by Claude*

## Run localy
1. You need 2 Terminals
2. In one terminal go run `cd backend` and the other `cd frontend`
3. In both, run `npm install`
4. In both backend and frontend, make a .env file and fill it in. You can use a custom API key
5. Run in the backend `npm start` and in the frontend `npm run build` and `npm run preview`
6. Open https://localhost:4173
